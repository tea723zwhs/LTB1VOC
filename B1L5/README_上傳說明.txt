B1L5 Flashcards — GitHub Pages 部署說明

1. 解壓縮後把整個 B1L5 資料夾上傳至 GitHub 儲存庫 tea723zwhs/LTB1VOC 的根目錄。
2. 在 GitHub 的 Code 頁面打開 B1L5，確認直接看得到 index.html 和 assets/images。
3. GitHub Pages 已使用 main / (root) 發布時，這個單元的網址應為：
   https://tea723zwhs.github.io/LTB1VOC/B1L5/
4. 請不要只上傳 index.html；21 張 WebP 必須與網頁一起保留原目錄層級。

單字與圖片均擷取自使用者提供的 Lesson_5_vocabulary_flashcards(1).pptx（共 21 張投影片）。
功能：看圖猜字、選圖聽音、洗牌。英文發音使用瀏覽器內建 Speech Synthesis，並無獨立音檔。
提醒：部分手機瀏覽器需要使用者按下「播放英文」才能播放語音。
